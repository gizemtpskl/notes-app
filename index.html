Opening your notes…

This app needs a small local server

Browsers block JavaScript modules on pages opened directly from a file, so the app can't start this way. There are two ways to run it:

On your computer

In a terminal, go to this folder and run:

python3 -m http.server 8000

Then open http://localhost:8000.

Online

Publish the folder with GitHub Pages. Your notes still stay in your browser and are never uploaded.

The app couldn't start

Try reloading the page. If that doesn't help, update your browser to a recent version. Your saved notes aren't affected.
